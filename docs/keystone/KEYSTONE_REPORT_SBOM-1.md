## 5. Known limitations

5.1 An SBOM describes one resolution (2026-10-01). Users' resolvers
    may install newer versions; regenerate at every release.
5.2 Licences are taken from package metadata as published on PyPI,
    not from reading each project's LICENSE file.
5.3 The published wheel 1.1.0 predates this SBOM; it ships with the
    next release (1.2.0).
5.4 The gate checks the committed SBOM against `pyproject_probe.toml`;
    it does not re-resolve, because the gate runs offline.
5.5 The MPL-2.0 assessment is a reading of the licence, not legal
    advice.
